# Чудо Обувь

Учебный каталог обуви: Python, PySide6, SQLAlchemy и PostgreSQL.

## Запуск

Из корня репозитория в PowerShell:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
$env:DATABASE_URL = "postgresql+psycopg://USER:PASSWORD@HOST:5432/TufliBatinkoKrosovki"
.\.venv\Scripts\python.exe widget.py
```

Замените USER, PASSWORD и HOST своими параметрами. База данных должна существовать; приложение создаёт таблицы при запуске. Без DATABASE_URL используется PostgreSQL на localhost с базой TufliBatinkoKrosovki. `.env.example` показывает формат настройки; автоматически файл .env не загружается.

Сначала открывается окно входа (`login.py`, `login.ui`). Введите логин и пароль пользователя из таблицы `users` или нажмите «Войти как гость». После успешного входа каталог показывает имя пользователя и разрешает сортировку цены; гостю сортировка недоступна. Неверные данные и ошибки подключения отображаются в окне входа.

Для первоначального импорта таблиц из `import/` в подготовленную базу:

```powershell
.\.venv\Scripts\python.exe import_data.py
```

В импортированных пользователях паролей нет. Назначьте пароль существующему пользователю командой ниже, заменив LOGIN его логином из `Users_import.xlsx`:

```powershell
.\.venv\Scripts\python.exe set_password.py LOGIN
```

Команда дважды запрашивает пароль скрытым вводом и сохраняет хеш PBKDF2 с индивидуальной солью в `users.user_pas`. Она использует ту же переменную `DATABASE_URL`. Пустые пароли не разрешают вход. Существующие учебные пароли, записанные обычным текстом, также поддерживаются; команда назначения заменяет их хешем.

## Последние правки интерфейса

В основной версии выпадающий список сортирует товары по цене по возрастанию и убыванию; пункт «по умолчанию» возвращает порядок по ID. Окно входа автоматически передаёт проверенного пользователя в `Widget(user=user)`. Для гостя список отключён. При программной смене пользователя доступны `window.set_user(user)` и `window.set_user(None)`; смена пользователя сбрасывает сортировку.

В `preview/` сохранён снимок интерфейса от 05.11.2026 13:06: скидка 25% на товары без заказов в прошлом месяце, подсветка малого остатка и обновлённое оформление. Там же находятся скриншоты. Этот снимок не содержит новой сортировки из основного `widget.py`.

Чтобы применить эту версию в своей копии, скопируйте `widget.py`, `tovar.py`, `form.ui`, `tovar.ui` из `preview/` в корень с заменой, затем пересоздайте Python-код формы:

```powershell
.\.venv\Scripts\pyside6-uic.exe form.ui -o ui_form.py
.\.venv\Scripts\python.exe widget.py
```

Изображения товаров и логотипа отсутствуют в сохранённых исходниках. Каталог показывает «Нет фото», если изображения не найдены.

## Проверка публикации

Сортировка проверена запуском настоящего окна Qt в режиме offscreen с изолированной SQLite: гость, передача пользователя после входа, оба направления цены, возврат к порядку по ID, выход из аккаунта, равные и пустые цены, пустой каталог. Рабочая PostgreSQL при этой проверке не использовалась. Сохранённое окружение `.venv` ссылается на Python с другого компьютера; для обычного запуска создайте своё окружение по инструкции выше.

Окно входа также проверено с настоящими кнопками Qt и тестовой SQLite: неверный и пустой пароль, отсутствующий и повторяющийся логин, недоступная база, вход клавишей Enter, передача пользователя в каталог с сортировкой, гостевой режим, проверка старых паролей и назначение нового хешированного пароля.
