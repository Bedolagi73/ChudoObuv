# Чудо Обувь

Учебный каталог обуви: Python, PySide6, SQLAlchemy и PostgreSQL.

## Запуск

Из корня репозитория в PowerShell:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item .env.example .env
```

Текущее подключение: PostgreSQL `217.71.129.139:4099`, база `chudo_obuv`, пользователь `postgres`. В `.env` замените PASSWORD своим паролем. После сохранения файла запустите приложение из Qt Creator или командой:

```powershell
.\.venv\Scripts\python.exe widget.py
```

Файл `.env` автоматически читается рядом с `models.py`, независимо от рабочей папки Qt Creator. Переменная DATABASE_URL, уже заданная в среде запуска, имеет приоритет. Каталог использует существующие таблицы `chudo_obuv`; при запуске приложение только читает данные. Без настройки приложение показывает сообщение о необходимости заполнить `.env`. При недоступной базе показывается понятное сообщение. `.env` исключён из Git.

Для чтения `.env` используется [python-dotenv](https://github.com/theskumar/python-dotenv#readme); после обновления проекта установите зависимости заново: `python -m pip install -r requirements.txt` в окружении, выбранном в Qt Creator.

Приложение сразу открывает каталог товаров. Авторизация временно убрана; сортировка цены доступна сразу.

В `chudo_obuv` товары уже загружены, повторный импорт для запуска не требуется. Команда ниже предназначена для первоначальной загрузки в отдельную пустую базу той же структуры:

```powershell
.\.venv\Scripts\python.exe import_data.py
```

## Последние правки интерфейса

В основной версии выпадающий список сортирует товары по цене по возрастанию и убыванию; пункт «по умолчанию» возвращает порядок по ID. Слева под сортировкой расположены надпись «Поиск» и поле `lineEdit`.

В `preview/` сохранён снимок интерфейса от 05.11.2026 13:06: скидка 25% на товары без заказов в прошлом месяце, подсветка малого остатка и обновлённое оформление. Там же находятся скриншоты. Этот снимок не содержит новой сортировки из основного `widget.py`.

Чтобы применить эту версию в своей копии, скопируйте `widget.py`, `tovar.py`, `form.ui`, `tovar.ui` из `preview/` в корень с заменой, затем пересоздайте Python-код формы:

```powershell
.\.venv\Scripts\pyside6-uic.exe form.ui -o ui_form.py
.\.venv\Scripts\python.exe widget.py
```

Изображения товаров и логотипа отсутствуют в сохранённых исходниках. Каталог показывает «Нет фото», если изображения не найдены.

## Проверка публикации

Каталог проверен запуском настоящего окна Qt в режиме offscreen с изолированной SQLite: открытие без авторизации, доступная сортировка по обоим направлениям цены, возврат к порядку по ID, равные и дробные цены, пустой каталог, ввод в поле поиска. Рабочая PostgreSQL при этой проверке не использовалась. Сохранённое окружение `.venv` ссылается на Python с другого компьютера; для обычного запуска создайте своё окружение по инструкции выше.

Дополнительно проверены запуск из другой рабочей папки с `.env`, приоритет переменной среды и сообщения при отсутствующей, некорректной или недоступной базе данных. Параметры подключения и пароль в сообщениях об ошибках не выводятся.

Модели адаптированы к таблицам `categories`, `sub_categories`, `product_items` и `order_items`. Названия атрибутов, используемые карточками товаров, сохранены. Каталог и сортировка дополнительно проверены на существующей PostgreSQL `chudo_obuv` с принудительным режимом READ ONLY; таблицы и данные при проверке не менялись.
